# English translations of annotator notes

Reference translations of **all 31 nonempty notes**: 26 from annotator 1 and
five from annotator 2. The other 169 judgments contain no free-text note.
Each German original appears beside its English translation. The comments
express the annotators’ assessments; the English versions are editorial
translations of those assessments. Quantitative analysis continues to use
the original submitted judgments.

Source: [published annotation data](../../src/legal_repro/assets/human_evaluation/annotations.json)
at commit `77365bf409fbd4c2a15cee2cfb4bb7de58872e09`.
[notes.csv](notes.csv) contains both languages, question/annotator identifiers,
the original label mapping and any translation note.

Question numbers follow the original 100-question packet order. A–D refer to
the labels seen by that particular annotator; the mapping is shown for each
note. Download/open the [offline report](../index.html) to inspect the full
question and answer texts. The reference-issue flag and ranked/ungradable
status are retained in the CSV.

For paper citations, use a commit permalink to this page with the relevant
heading anchor, for example `#annotator-1-question-2`.
See also the [English prompts and annotation instructions](../../prompts/en/README.md).

```text
Die Referenzantwort bezieht sich auf die fristlose Kündigung. Inwiefern diese jedoch im gegebenen Fall einschlägig sein soll, erschließt sich nicht.
```
